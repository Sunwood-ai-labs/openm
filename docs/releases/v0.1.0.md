# OpenM v0.1.0

OpenMの初回公開リリースです。Open WebUI `v0.6.5`のUI・認証基盤を土台に、
Claude Agent SDK、LiteLLM、GLM、ユーザー別Sandbox、タスク別Git worktreeを
一つのセルフホスト型コーディングエージェント環境として統合しました。

- [v0.1.0導入ウォークスルー](https://github.com/Sunwood-ai-labs/openm/blob/main/docs/guides/openm-v0.1.0-walkthrough.md)
- [仕様・実装計画書](https://github.com/Sunwood-ai-labs/openm/blob/main/docs/openm-specification.md)
- [検証レポート](https://github.com/Sunwood-ai-labs/openm/blob/main/docs/openm-validation.md)

## ハイライト

### エージェント中心のチャットUI

- Open WebUIの会話体験を残しながら、Claude Codeの作業を一つのタスク画面へ統合
- 現在の作業、ツール実行、Todo、権限要求、変更ファイル、diff、コストを実イベントから表示
- 完了回答をOpen WebUI標準のMarkdownレンダラーで描画
- デスクトップと390×844のモバイル表示に対応

### Claude Agent SDKのライブ実行

- Claude Agent SDKセッションをタスクごとに起動
- 認証付きSSEでSDKの部分テキスト、ツール実行、状態変化をブラウザへ逐次配信
- 完了時の回答をまとめて待たず、生成途中から画面へ反映
- `demo`と`live`の実行モードを用意

### ユーザーとタスクの分離

- ユーザーごとに永続Workspaceを分離
- タスクごとに専用Git branchとworktreeを作成
- 既存ファイルの編集に加え、新規未追跡ファイルもChangesとdiffへ表示
- プロジェクト、タスク、イベント、権限要求を認証ユーザー単位で保存

### 権限ゲート

- Claude Agent SDKのツール要求をOpenMの権限画面へ接続
- 「今回のみ許可」「このタスクで許可」「拒否」を選択可能
- 権限待ち、再開、成功、失敗、キャンセルをタスク状態として可視化

### LiteLLMとGLM

- LiteLLM ProxyをDocker Composeへ同梱
- `claude-glm-code`と`claude-glm-main`のモデルエイリアスを提供
- v0.1.0では両エイリアスを`zai/glm-4.5-flash`へルーティング
- LiteLLM側でリトライ、パラメータ調整、APIキー情報の秘匿を設定

## セルフホスト

```powershell
Copy-Item .env.openm.example .env.openm
# .env.openm に ZAI_API_KEY を設定
docker compose --env-file .env.openm -f docker-compose.openm.yaml up --build
```

既定の公開ポートは`3000`です。変更する場合は`OPENM_HOST_PORT`を指定します。
ユーザーデータとworktreeは`openm-data` volumeへ保存されます。

## 検証

- `PYTHONPATH=backend .venv/Scripts/python.exe -m pytest backend/open_webui/test/openm -q`
- `npm run build`
- `docker compose --env-file .env.openm.example -f docker-compose.openm.yaml config --quiet`
- Claude Agent SDK + GLMによるファイル作成、Read検証、変更ファイル集計
- 回答本文が完了前から増えるSSEストリーミング
- Markdownの見出し、太字、箇条書きのDOM描画
- 390×844での横方向オーバーフロー確認

詳細な実行結果は[検証レポート](../openm-validation.md)を参照してください。

## 既知の範囲

- v0.1.0は単一ホストのDocker Compose構成を対象とします。
- モデルエイリアスは設定ファイルでGLM 4.5 Flashへ固定されています。
- worktreeの変更はタスク内に保持され、自動で`main`へマージされません。
- Open WebUI全体の既存型・アクセシビリティ警告は、このリリースのOpenM固有検証とは別扱いです。
